# SelectionPal（划词助手）

一个免费、轻量、原生的 macOS 全局划词工具。选中文字后，可以直接使用英式或美式发音，也可以在中文和英文之间翻译。

![SelectionPal 使用效果](assets/selectionpal-demo.png)

## 为什么做这个工具

Easydict 的功能很完整，但对我来说有些过于复杂，其中不少功能在日常复习时并不会用到。PopClip 的交互更简洁、产品也比较成熟，但需要付费使用。

因此，我做了 SelectionPal：一个面向复习场景的小型划词工具，只保留英式发音、美式发音和中英文互译这些常用功能，希望在阅读课件和资料时做到划词即用，尽量减少额外操作和干扰。

目前仅支持 macOS，暂不支持 Windows 和 Linux。

## 功能

- 全局鼠标划词后显示原生悬浮操作条
- 英式英语和美式英语朗读
- 中文翻译为英文、英文翻译为中文
- 划词操作条提供四则 / 次方、GCD、LCM、取余、模幂、模逆元，以及进制转换
- 计算结果直接显示在浮条下方，没有独立工具窗口或参数表单
- 浮条“判断”通过本机 Codex 检查任意主题的中英文事实陈述，显示对错与简短解释，必要时联网查证
- 支持 Codex 等未完整暴露辅助功能选区的应用
- 兼容取词后完整恢复原剪贴板
- 点击其他位置、滚动、切换窗口或按键时自动关闭
- 自动适配 macOS 浅色和深色外观
- 翻译、发音和计算不需要 API Key；AI 判断需要本机 Codex 已用 ChatGPT 账号登录

## 系统要求

- macOS 15 或更高版本
- Swift 6.2 / Xcode 26（仅构建时需要）
- Node.js（仅生成内置计算器及运行计算测试时需要；应用运行不需要）
- 需要授予辅助功能权限

## 构建

```bash
chmod +x build-app.sh
./build-app.sh
open "dist/划词助手.app"
```

构建产物位于 `dist/划词助手.app`。

计算测试：`node Calculator/build.mjs && node Calculator/test.cjs`。

## 使用

1. 启动“划词助手”。
2. 打开“系统设置 → 隐私与安全性 → 辅助功能”。
3. 允许“划词助手”访问辅助功能。
4. 在任意支持的应用中拖动选择文字，或者双击选择单词。
5. 在悬浮操作条中选择英式发音、美式发音或翻译方向。
6. 需要计算时点“计算”，选择运算，直接查看结果。

例如划选 `2^128` →“计算 → 四则 / 次方”；划选 `540,144` →“计算 → 最大公约数”。无需填写表单。

进制转换：划选 `255` →“计算 → 进制转换 → 自动识别”，同时显示二、八、十、十六进制。`0b`、`0o`、`0x` 前缀自动识别；无前缀的 `FF` 可选“按十六进制读取”。无前缀默认十进制，不猜测 `1010` 的来源。仅支持整数，负数以负号显示，不按补码解释。结果右侧的小按钮可复制完整内容。

小数和分数使用精确分数计算，大整数次方不会被浮点数截断。参数格式见[计算功能清单](计算功能清单.md)。

翻译首次使用时，macOS 可能提示下载对应语言包。

### 判断对错（不限课程）

无需导入课件，也不要求课堂知识。划选中英文事实陈述，点浮条末尾的“判断”，直接显示正确／错误、中文理由；错误时给出更正。涉及最新信息或需要核实的专业知识，会允许 Codex 搜索可靠来源并附链接。完整结果可用右侧按钮复制。

例如 `Photosynthesis converts light energy into chemical energy.` 可判断为正确；`所有质数都是奇数。` 应判断为错误（2 是偶质数）。信息不足、指代不清、主观意见或无法核实的时效性事实显示“暂无法判断”，不会强行二选一。AI 可能出错，不代替专业建议。

需要安装新版 Codex CLI 或 ChatGPT 桌面应用，并通过 ChatGPT 账号登录。每次主动点击才发起联网请求，消耗自己的 Codex 额度。工具不复制登录凭证、不设置模型、不自动改用 API Key。切换选区、翻译或计算时取消旧请求，90 秒无响应则提示超时。

接入方式沿用 [Codex 官方非交互调用说明](https://learn.chatgpt.com/docs/non-interactive-mode)：只读沙箱、临时会话、隔离用户工具配置，允许网页事实检索，但不开放 shell 或插件。共享工具不共享登录凭证，每个人需要自己的账号。

本地测试（不联网）：

```bash
swiftc -parse-as-library Sources/CourseJudge.swift Tests/JudgeChecks.swift -o /tmp/selectionpal-judge-checks
/tmp/selectionpal-judge-checks
```

加 `--live` 可核验跨学科、中英文、模糊陈述及官方网页核查，会使用 Codex 额度；`--smoke` 只测试一句。

## 隐私

- 应用仅在用户主动划词后读取当前选区。
- 不保存翻译原文与译文。
- 语音使用 macOS 系统语音合成。
- 翻译使用 Apple Translation 框架。
- 计算在本机 JavaScriptCore 内运行，不加载网页、不调用服务器、不保存选区或计算历史。
- 点击“判断”只把选中陈述交给 Codex，不再读取或发送已导入的课件。必要时相关查询会发送给网页搜索服务，避免划选密码等敏感内容。临时请求文件结束后清理，Codex 自身的数据处理规则仍适用。以前导入的课件仍保留在本机 Application Support，没有删除。
- 兼容模式会临时复制选区，并在读取后恢复原剪贴板内容。

## 已知限制

- 当前仅支持 macOS。
- 部分应用可能阻止辅助功能读取或模拟复制，因此无法获取选区。
- 本地构建采用临时签名；公开分发需要 Apple Developer ID 签名和公证。
